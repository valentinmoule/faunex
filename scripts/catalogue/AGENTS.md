Use the existing snapshot-backed approved rename function and verified scientific identities; do not infer species from generic development stages, because a larva label alone cannot prove an adult species.

## Generic groups require individual review

Use `reclassify_exact_generic_capture` only for a historical photo already carrying its unique existing species binomial; use bounded `enrich-capture` previews without writes for other photos, because a generic group cannot establish one species for all its captures.
